Files in Credentials Portal are attached to individual people. Common uses include uploading signed forms, background check documents, quiz results, or other supporting materials related to a candidate's credentialing process.

[Screenshot: Files section on a person's profile showing uploaded documents with names and dates]

## Upload a file

<Steps>
  <Step title="Open a person's profile">
    Navigate to **People** and click on the person you want to upload a file for.

    [Screenshot: People list with a person's profile card highlighted]
  </Step>
  <Step title="Go to their Files tab">
    On the person's profile, click the **Files** tab.

    [Screenshot: Person profile with the Files tab selected]
  </Step>
  <Step title="Upload">
    Click **Upload File** and select a file from your device. Supported formats include PDF, Word documents, images, and common office file types.

    [Screenshot: File upload button and drag-and-drop area]
  </Step>
  <Step title="Add a name (optional)">
    Give the file a descriptive name so others can identify it easily.
  </Step>
</Steps>

## Interview file attachments

Files can also be attached directly to interview records during the interview documentation process. These appear in the interview form under file attachment fields.

See [Conducting Interviews](/help/board-members/interviews) for more on interview-specific attachments.

## Manage files

Administrators can:
- **Rename** a file by clicking its name and editing it
- **Delete** a file by clicking the delete icon
- **Reassign** a file to a different person (from the district-wide Files view in Settings)

[Screenshot: File management options including rename and delete]

## Who can see files

File visibility follows role permissions:

| Role | Access |
|------|--------|
| **Admin** | All files for all people |
| **Board Member** | Files for people they interview |
| **Mentor** | Files for their assigned candidates |
| **Candidate** | Their own files only |

## File storage

Files are stored securely and accessed only through the Credentials Portal application. Direct file URLs are authenticated — files cannot be accessed without a valid session.
