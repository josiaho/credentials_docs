As a district administrator, you have full access to manage every aspect of your Credentials Portal district — from adding people and configuring roles to managing billing and integrations.

## Admin permission flags

The Admin role grants a set of permission flags. Custom roles can combine these flags in any way:

| Flag | What it allows |
|------|---------------|
| `People (edit)` | Add, edit, and delete people in the district |
| `Settings` | Edit district configuration |
| `Roles` | Create and modify roles |
| `Interviews (edit)` | Create and edit all interviews |
| `Broadcasts` | Send district-wide broadcast messages |
| `Billing` | View and manage subscription and billing |

## Inviting people

After adding someone to the district, send them an invitation email so they can log in. See [Managing People](/help/admin/people) for step-by-step instructions.
